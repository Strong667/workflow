# Слой UI-библиотеки

Здесь собрано всё, что знает о PrimeVue. Остальной код обращается к библиотеке
только через эти файлы, поэтому смена мажорной версии (или самой библиотеки)
затрагивает один каталог.

| Файл | Отвечает за |
| --- | --- |
| `theme.ts` | пресет темы, фирменные цвета, конфигурация плагина |
| `global-components.ts` | глобальная регистрация лёгких компонентов |
| `lazy-components.ts` | реэкспорт тяжёлых компонентов для локальных импортов в экранах |
| `locales.ts` | подписи внутри компонентов библиотеки для ru/en/kk |
| `tokens.ts` | чтение значений токенов темы (нужно Chart.js, он не понимает CSS-переменные) |
| `feedback.ts` | уведомления и диалог подтверждения в терминах приложения |

Порядок обновления до PrimeVue 5 описан в `docs/PRIMEVUE-5.md`.
